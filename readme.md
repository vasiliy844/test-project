# Тестовое задание — Junior Web-разработчик

Одностраничный сайт «О компании» для интернет-магазина «Рыжий кот»,
свёрстанный по макету Figma, с popup-формой обратной связи,
валидацией на JavaScript и обработкой на PHP.

---

## Что реализовано

- **Вёрстка страницы** «О компании»: шапка, хлебные крошки, заголовок,
  блок «Компания в цифрах», фото склада, текстовые блоки, списки
  производств и торговых марок, футер.
- **Адаптивная вёрстка** под десктоп, планшет и мобильные
  (медиа-запросы на 900px, 640px, 460px).
- **Popup-форма обратной связи** с полями «Имя» и «E-mail».
- **Клиентская валидация** на JavaScript.
- **AJAX-отправка** формы через Fetch API без перезагрузки страницы.
- **Серверная валидация** на PHP и возврат JSON-ответа.

---

## Технологии

- **HTML5** — семантическая разметка.
- **CSS3** — Flexbox, CSS Grid, CSS-переменные, медиа-запросы.
- **JavaScript (ES6+)** — DOM, события, Fetch API, async/await.
- **PHP 8** — обработка POST-запроса в формате JSON, серверная валидация.

**Без сторонних библиотек и фреймворков** — только нативные технологии,
как того требует задание.

## Как запустить проект

## Требования

- **PHP 8 или выше**
- Любой современный браузер (проверялось в Google Chrome)
- Редактор кода — Visual Studio Code (рекомендуется)

## Проверка установки PHP

Откройте терминал и выполните:

```bash
php -v
```

Если PHP установлен корректно, вы увидите его версию.

## Запуск

1. Скачайте или склонируйте проект:

```bash
git clone <https://github.com/vasiliy844/test-project.git>
cd test-project
```

2. Откройте папку проекта в VS Code.

3. Запустите встроенный PHP-сервер из папки проекта:

```bash
php -S localhost:8080
```

4. Откройте в браузере:

http://localhost:8080/index.html

## Как проверить работу

1. Страница открывается без ошибок в консоли DevTools.

2. Адаптивность — сузьте окно браузера, проверьте перестроение сетки «Компании в цифрах» и футера.

3. Popup — нажмите кнопку «Форма обратной связи»; закройте крестиком, кликом по затемнённой области или клавишей Escape.

4. Валидация JS:

- пустое имя → ошибка;

- имя из 1 символа → ошибка;

- пустой e-mail → ошибка;

- e-mail без @ или без домена → ошибка.

5. AJAX — при корректных данных страница не перезагружается,
   внизу формы появляется сообщение «Спасибо, заявка принята!»,
   через 2 секунды popup закрывается сам.

6. Серверная проверка — откройте DevTools → Network → отправьте форму.
   Увидите POST /index.php со статусом 200 и JSON-ответом.

## Принятые решения

**Popup**
Реализован на чистом CSS + JS-класс is-open. Закрытие работает
тремя способами: крестик, клик по оверлею (элементы помечены атрибутом
data-close) и клавиша Escape. Во время открытия блокируется скролл
фона через body.style.overflow = 'hidden'.

**Валидация — двойная**

- На клиенте (JS) — мгновенная обратная связь пользователю,
  ошибки появляются под полями по мере ввода.

- На сервере (PHP) — защита от подмены данных через DevTools
  или отправки запроса в обход формы.

JavaScript работает в браузере пользователя, и ему нельзя полностью
доверять, поэтому повторная проверка на сервере обязательна.

**AJAX через Fetch API**
Выбран формат JSON (Content-Type: application/json), потому что
он удобнее для структурированных данных и хорошо читается в обе стороны.
Отправка идёт через fetch() с async/await, ответ сервера — тоже JSON
с полями success и message.

**Адаптивность**
Медиа-запросы на трёх контрольных точках:

- 900px — сетка «Компании в цифрах» 4 → 2 колонки,
  футер 4 → 2 колонки;

- 640px — уменьшены отступы, шрифты, размеры иконок,
  футер остаётся в 2 колонки, блок контактов переносится на всю ширину;

- 460px — футер в одну колонку, минимальные отступы.

**Стили**
Использованы CSS-переменные для цветов (--color-primary,
--color-accent и т. д.) и БЭМ-нейминг классов —
это упрощает поддержку и чтение кода.
